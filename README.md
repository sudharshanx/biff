# BIFF

Agent skill for writing a short reply to a hostile email, text, or public attack: Brief, Informative, Friendly, and Firm.

Generated from *BIFF: Quick Responses to High-Conflict People, Their Personal Attacks, Hostile Email and Social Media Meltdowns* by Bill Eddy with [book-to-skill](https://github.com/virgiliojr94/book-to-skill). The files are synthesized practice notes, not the book text.

The author confirmed they are authorized to publish this derivative.

## Install

```bash
npx skills add https://github.com/sudharshanx/biff --skill biff
```

## Files

- `SKILL.md` — core decision rules and chapter index
- `chapters/` — eleven chapter notes with worked replies
- `glossary.md` — terms
- `patterns.md` — techniques
- `cheatsheet.md` — reply, silence, and the edit pass
- `evals/` — sample prompts used to check the skill

This skill is not legal advice and not a mental-health diagnosis. If someone may harm themselves or someone else, contact local emergency services or a suicide hotline.
